# Изјава за фискални рачун за гориво

PWA (Progressive Web App) која од слике фискалног рачуна за гориво прави
готову **изјаву у PDF-у** — за правдање трошкова сопственог превоза на посао.

Сликаш рачун телефоном → апликација очита **број рачуна (БИ)** из QR кода →
провериш/допуниш податке → добијеш једнострану A4 изјаву са приложеним рачуном →
поделиш је (Gmail, мејл, …).

**Све се ради у прегледачу. Ништа не одлази са уређаја. Ради и офлајн.**

## Како ради

1. **Корак 1 — Рачун.** Унесеш име, фирму/послодавца, место и (опционо) мејл
   примаоца — памти се на уређају, попуњава се само једном. Учиташ или сликаш
   потпис (бела позадина се аутоматски уклања). Сликаш фискални рачун.
2. **Корак 2 — Провера.** Из QR кода рачуна се аутоматски ишчита број рачуна
   (БИ — последњи сегмент ПФР броја). Датум је подразумевано данашњи — измениш
   ако треба. Видиш очишћену слику рачуна која иде у PDF.
3. **Корак 3 — PDF.** Генерише се једнострана A4 изјава (текст + потпис +
   приложен рачун). Поделиш је преко „Подели" (на Android-у се PDF сам прикачи
   као прилог) или преузмеш.

## Технички

Чист client-side, без бекенда:

| Шта | Како |
|-----|------|
| Читање QR кода | [`@undecaf/zbar-wasm`](https://github.com/undecaf/zbar-wasm) — zbar компајлиран у WebAssembly (JS QR библиотеке нису довољно робусне за густе QR кодове фискалних рачуна) |
| Број рачуна (БИ) | из бинарног `vl` записа QR кода (верзија 3, `uint32 LE` на офсету 17) — офлајн, тачно |
| Чишћење слике рачуна | canvas: grayscale → flatten позадине → адаптивни праг → auto-crop |
| PDF | [jsPDF](https://github.com/parallax/jsPDF) — изјава се исцрта на canvas, па угради у A4 |
| Дељење | Web Share API (`navigator.share` са фајлом), fallback на `mailto` нацрт |
| Памћење | `localStorage` (профил + потпис) |
| Офлајн / инсталација | `manifest.json` + `service-worker.js` (network-first за HTML, stale-while-revalidate за статику) |

Нема никаквог слања на сервер — нема ни сервера. Слика рачуна никад не напушта прегледач.

## Покретање

Статички фајлови — довољно их је сервирати преко **HTTPS** (камера, Web Share и
PWA инсталација траже secure context). На пример:

```
# било који статички сервер преко HTTPS, нпр.
python3 -m http.server      # за локални развој (камера ради и на http://localhost)
```

За телефон: отвори преко `https://...`, прихвати сертификат ако је self-signed,
па из менија прегледача „Add to Home screen" / кликни дугме **Инсталирај**.

## Структура

```
index.html            — UI (3 корака)
app.js                — сва логика (QR, обрада слике, PDF, дељење, PWA)
style.css             — стил
manifest.json         — PWA манифест
service-worker.js     — кеш / офлајн
icon-source.svg       — мастер за иконицу (ауто + QR + српска триколора)
favicon.*, *-icon*.png, web-app-manifest-*.png — генерисани деривати
vendor_js/            — zbar-wasm (+ .wasm), jsPDF — локално, без CDN-а
```

## Иконица

`icon-source.svg` је једини фајл који се едитује ручно. PNG/ICO деривати се
регенеришу из њега преко Chromium headless screenshot режима (детаљно у
[`ikonica.md`](ikonica.md) ако постоји, или у изворном `qrpay` пројекту).
После измене иконице — бумпуј `CACHE_VERSION` у `service-worker.js`.

## Приватност

Слике рачуна, потпис и лични подаци остају искључиво у прегледачу
(`localStorage` + обрада на canvas-у). Апликација нема бекенд, не шаље податке
нигде и ради потпуно офлајн након првог учитавања.
